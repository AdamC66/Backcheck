# Hockey Analytics Dashboard

Dashboard for hockey team staff/admins to review their team's analytics.

Status: architecture/standards scaffolded, no application code yet. See `docs/PLANNING.md` for current phase.

## Stack

- Backend: Ruby on Rails (API-only) + PostgreSQL, Dockerized
- Frontend: React + TypeScript + Tailwind (Vite vs Next.js: TBD, see `docs/DECISIONS.md`)
